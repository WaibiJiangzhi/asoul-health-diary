# Asoul 一个魂生活日记

Windows 本地使用时请双击 `Asoul一个魂健康日记.cmd`：启动器会在后台建立仅限本机访问的网页服务并打开 `http://127.0.0.1:4179/index.html`，这样周报 PNG 和表情图片都能正常处理。不要直接双击 `index.html`，`file://` 模式会受到浏览器的图片导出限制。也可以部署到 GitHub Pages、Cloudflare Pages 等静态托管服务。页面不需要远程后端，记录默认保存在当前浏览器的本地存储中。

## 个人档案与目标倒计时

- 个人档案可以填写姓名、性别、年龄和个性签名；不收集身高或项目。
- “目标与倒计时”独立于所有空间，适合考研初试、生日、项目交付或旅行等明确日期。
- 最多保留 4 个倒计时。先点选卡片，再用右上角按钮编辑或删除；也可以给倒计时选择一个表情。1、2、3、4 条记录会自动使用不同的卡片布局。
- 点选倒计时后，可以用“向前 / 向后”调整首页顺序；这个顺序也会同步用于周报和下载图片。进度目标使用相同的排序方式，刷新和恢复数据后都会保留。
- 新建或编辑倒计时时，可以不选空间，也可以勾选一个或多个空间。它始终显示在首页，只会进入所选空间的周报；不选时仅在首页显示。旧备份里的倒计时默认关联已有全部空间。
- 页面按今天显示剩余天数；周报则按该周周日计算当时的倒计时，因此复盘时能看到那一周距离目标还有多远。

倒计时下面还有独立的“进度目标”，适合背单词、读书页数、跑量或项目完成度。建立时填写总目标、单位、当前进度和默认调整量；之后直接在卡片上调整，正数增加、负数减少，进度最低不会小于 0。最多保留 6 个进度目标，每个目标保留最近 100 次调整记录。进度目标也可以选择表情，并像倒计时一样不选、单选或多选周报空间；未选择空间时只在首页显示。

## 自定义空间

- 初次使用只提供一个“健康”空间；考研、工作或其他空间由用户按需新建，手机端通过左右切换选择空间。
- 空间标题右侧的“+”和“•••”分别用于新建和管理空间；模板、名称和图标都可以随时修改。
- 空间图标既可以使用一个符号，也可以展开表情选择器，从嘉然、乃琳、贝拉表情包中选择。表情列表按文件夹编号从大到小显示，选择器收起时不会加载整包图片。
- 最多保留 8 个空间。不同空间的年月、周计划、打卡状态、周报、曲线图和 AI 背景资料彼此隔离。
- 示例空间可以全部删除；没有空间时，个人档案和首页倒计时仍能独立使用。
- 删除空间会同时删除该空间中的全部记录和图表，并自动解除倒计时、进度目标与该空间的周报关联；首页目标本身不会被删除。请先确认空间数据不再需要或下载完整备份。

模板只决定字段名称和示例，不限制空间用途。例如学习模板既可以叫“考研”，也可以叫“日语”“资格证”或“每日阅读”。

## 年月与固定周条

1. 进入一个空间后点击“新建年月”。
2. 网页会自动生成该月所有以周一为开始日的周条，不需要逐周新建。
3. 每一周固定包含 Day1 到 Day7，对应周一到周日；跨月的后几天仍归入周一所在的年月。
4. 同一空间、同一年月只能建立一次。
5. “删除年月”会删除该年月的所有安排、打卡状态和当天小记，但不会影响其他年月或其他空间。
6. 更多操作里的“清空当前日卡”只重置正在查看的一天；“清空当前周卡”会重置该周七天。两者都会保留所属空间、日期和卡片位置，并在执行前再次确认。

每个周条使用独立的信息卡，集中显示 `WEEK 01`、日期范围和 7 天记录进度；进入年月时会优先定位到今天所在的一周，没有本周时则选择最近的一周。

旧版记录会自动迁移：原有空间会保留，旧周计划会统一对齐到周一，并自动补齐已有年月中缺少的固定周条。旧版分开的“计划 / 完成记录”会合并为一条安排，原来的完成勾选会转成 `✓` 或 `×`；旧健康记录中的饮食安排也会成为普通安排。恢复前仍建议先保留一份原始备份。

## 每日计划

- 每个空间都使用通用的“今日重点”；健康空间仍可额外记录体重，饮食、运动、睡眠等都作为普通安排填写。

每项安排只占一行，执行后点右侧状态按钮选择 `✓ 完成`、`⚡ 调整过计划` 或 `× 未完成`。计划临时变化时，直接把这一行改成最终执行的安排并标记 `⚡`；不再额外填写一份“实际完成”。当天还可以保留小记、整体状态和嘉然、贝拉、乃琳表情。

周卡中的“已记录天数”采用明确标记：在当天编辑器点“记录今天”后立即计入，再点一次可以取消。只填写计划不会自动增加天数。Day1—Day7 在手机上一次显示一天，使用标题旁的左右箭头切换。旧版中已经填写完成情况、小记或体重的日期会在升级时尽量保留为已记录。

## 和 AI 一起规划

先建立年月、点选要安排的周条，再点击“AI 规划本周”：

1. 如有需要，展开“补充我的情况与偏好”，填写当前基础、目标、可用时间、喜好和限制；这些资料只保存在当前空间。
2. 点击“复制上周情况”，粘贴到你习惯的 AI 对话。网页会同时带上刚才填写的情况和当前空间更早一周的真实记录。
3. 点击“复制计划模板”，继续粘贴到同一个 AI 对话。模板包含本周固定日期、Day1—Day7 和网页可识别的格式。
4. 把 AI 返回的完整计划文本粘贴到弹窗最下面，点击“导入周计划”。

弹窗中的“打开豆包”只是一个可选快捷链接；PWA 中也可以跳转，系统会在浏览器或新的网页窗口打开豆包，不会自动发送日记内容。

如果当前空间存在更早一周，提示词会自动附上上一周的打卡数据，帮助 AI 调整任务量。导入只更新当前选中周的每日类型、重点和计划安排，不会生成或修改当天小记，也不会覆盖打卡状态、整体状态、体重或表情。普通用户不需要接触 JSON。

## 顺延与周报

- 先点选某一天，再点击“从 DayX 起顺延一天”：所选日期之前保持不变，从所选日期到 Day6 的全部内容移到下一天，所选日期清空，原 Day7 内容丢弃。执行前会再次确认。
- “显示周报”会汇总选中周的打卡状态、计划安排、当天小记、体重（仅健康模板）、表情，以及被指定显示在当前空间的倒计时和进度目标。
- “下载高清竖版”会生成 2160 像素宽的手机长图与完整单列周报，Day1 到 Day7 不会再出现最后一张落单的问题。
- “下载 4K 横版”会生成 3840 × 2160 的一页摘要，适合电脑查看、做封面或发到群里。
- “复制纯文本”可复制 Markdown 周报，适合交给 AI 做复盘或保存到其他笔记工具。

## 曲线图

每个模板会显示对应的快速示例，也可以自定义图表名称、横轴和最多三项指标。每项指标都能分别设置纵轴最小值与最大值，留空则继续自动计算。新增节点后，可以给不同曲线分别选择表情；图表支持排序、缩放和横向查看。日期节点内部建议保存为 `YYYY-MM-DD`，横轴会显示成清楚的月/日；跨年时会在第一个节点和年份切换处补充两位年份。

曲线的默认 `1×` 是全局视图：长期数据会保留全部曲线和节点命中区域，只抽稀圆点与表情，避免 300 天记录挤成一团。连续点击“放大”可逐级查看局部；“最大”会按当前屏幕和节点数量动态计算横向画布，让每个已记录日期都拥有可读刻度，而不是固定停在某个倍率。放大后，被抽稀的节点装饰会逐步恢复，手机、平板和电脑遵循同一套规则。“下载曲线图”会生成 3840 × 2160 的 4K 轨迹卡，曲线、日期刻度和表情节点会一起保存。

## 导航与手机安装

- 手机端底部固定显示“首页、目标、空间、曲线、个人”五个入口，并像应用页签一样只显示当前版面：首页保留欢迎页和冷笑话，空间页把空间切换与周计划放在一起，个人页集中管理档案、提示音、安装和数据。再次点击当前“目标”入口会在倒计时与进度目标之间切换；浏览器返回键也能返回上一个版面。
- 部署到 Cloudflare Pages 或通过本地启动器打开后，浏览器允许安装时，“个人”页才会显示“一個魂”形象的“安装应用”按钮；安装完成后这张卡会自动消失。Android/电脑浏览器可直接点击安装；iPhone 请用 Safari 打开，点系统“分享”后选择“添加到主屏幕”。
- 在手机上查看真实效果，最方便的方法是部署到 Cloudflare Pages 后直接用手机打开网址；手机和电脑属于两个独立浏览器，想带上电脑记录时请先在电脑“备份”，再在手机“恢复”。电脑上也可以按 F12 打开设备模拟，快速检查手机排版。
- 第一次联网打开后，网页外壳和使用过的表情会按需缓存；暂时断网时仍可打开与查看本地数据。更新网站后，只有检测到新版本时顶栏才会出现“更新”，更新完成后自动消失，避免编辑过程中突然换版本。
- PWA 仍然是本地优先网页：安装到桌面后，日常修改仍会自动保存到这个应用来源对应的本机浏览器存储，关闭后重新打开会继续保留；安装不会把记录上传到服务器，也不会让不同浏览器自动同步。卸载应用、清除网站数据、换浏览器、换设备或更换域名之前，仍需先下载 JSON 备份。

## 数据与部署

- 点击“备份”会下载完整 JSON 备份；这里的 JSON 只用于整站用户数据迁移和恢复。冷笑话属于应用静态内容，不写入新备份。
- 点击“恢复”可导入新版生活日记备份，也兼容旧健康日记备份。
- 想先体验有一段记录后的完整页面，可以恢复 `sample-data/考研加健身用户示例.json`。它包含考研、健身两个空间，两个倒计时，过去与当前周记录，以及学习时长、体重和训练时长曲线图；恢复前请先备份自己的真实数据。
- 需要集中检查完整功能或长期曲线时，可以恢复 `sample-data/长期用户300节点示例.json`。其中个人档案、4 个倒计时、4 个进度目标、空间关联、每日记录、表情和周报均已填充；第一张长期图是连续 300 天单曲线，第二张是三项指标、300 个节点，用于检查全局抽稀、每日细节和性能。
- 部署到不同域名或从本地文件切换到 Cloudflare 后，浏览器会把它视为不同站点，原来的本地记录不会自动跟过去；请先备份，再到新站点恢复。
- 仓库中的 `本地备份文件`、`每周截图记录` 和 `发布` 已被 `.gitignore` 排除，不应上传个人记录。

## 主要文件

- `index.html`：网站入口，Cloudflare Pages 会直接识别。
- `js/app.js`：页面启动、事件、DOM 渲染、弹窗、图片导出和跨领域协调。
- `js/core/`：存储键、默认配置、数据迁移、当前结构归一化和本地保存生命周期。
- `js/domain/`、`js/ui/`：可复用领域计算与页面交互组件。
- `js/content/`：表情清单和默认冷笑话等静态内容。
- `css/design-system.css`、`css/pages/`：设计变量和五个页面的唯一样式入口。
- `css/legacy/`、`css/platform/`：迁移期共享基础组件、手机外壳和跨平台适配。
- `manifest.webmanifest`、`sw.js`、`icons`：手机/桌面安装、离线缓存和应用图标。
- `js/content/stickers.js`、`images/贝拉`、`images/嘉然`、`images/乃琳`：轻量表情资源。
- `js/content/冷笑话.js`：默认冷笑话。
- `sample-data/考研加健身用户示例.json`：可直接通过“恢复”导入的完整体验数据。
- `sample-data/长期用户300节点示例.json`：覆盖完整功能、密集曲线表情和长期数据压力的测试备份。

部署时需要保留上述文件及 `images/其他图片` 的相对目录结构。

开发者需要了解模块依赖、数据流和旧备份策略时，请阅读 `docs/JavaScript重构计划.md`。
