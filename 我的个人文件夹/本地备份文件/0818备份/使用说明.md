# Asoul 一个魂生活日记

Windows 本地使用时请双击 `Asoul一个魂健康日记.cmd`：启动器会在后台建立仅限本机访问的网页服务并打开 `http://127.0.0.1:4179/index.html`，这样周报 PNG 和表情图片都能正常处理。不要直接双击 `index.html`，`file://` 模式会受到浏览器的图片导出限制。也可以部署到 GitHub Pages、Cloudflare Pages 等静态托管服务。页面不需要远程后端，记录默认保存在当前浏览器的本地存储中。

## 个人档案与目标倒计时

- 个人档案可以填写姓名、性别、年龄和个性签名；不收集身高或项目。
- “目标与倒计时”独立于所有空间，适合考研初试、生日、项目交付或旅行等明确日期。
- 最多保留 4 个倒计时。先点选卡片，再用右上角按钮编辑或删除；也可以给倒计时选择一个表情。1、2、3、4 条记录会自动使用不同的卡片布局。
- 新建或编辑倒计时时，可以不选空间，也可以勾选一个或多个空间。它始终显示在首页，只会进入所选空间的周报；不选时仅在首页显示。旧备份里的倒计时默认关联已有全部空间。
- 页面按今天显示剩余天数；周报则按该周周日计算当时的倒计时，因此复盘时能看到那一周距离目标还有多远。

倒计时下面还有独立的“进度目标”，适合背单词、读书页数、跑量或项目完成度。建立时填写总目标、单位、当前进度和默认调整量；之后直接在卡片上调整，正数增加、负数减少，进度最低不会小于 0。最多保留 6 个进度目标，每个目标保留最近 100 次调整记录。进度目标也可以选择表情，并像倒计时一样不选、单选或多选周报空间；未选择空间时只在首页显示。

## 自定义空间

- 初次使用会提供健康、考研和工作三个示例空间。
- “新建空间”“编辑空间”“删除空间”三个入口放在一起；模板、名称和图标都可以随时修改。
- 空间图标既可以使用一个符号，也可以展开表情选择器，从嘉然、乃琳、贝拉表情包中选择。表情列表按文件夹编号从大到小显示，选择器收起时不会加载整包图片。
- 最多保留 8 个空间。不同空间的年月、周计划、完成记录、周报、曲线图和 AI 背景资料彼此隔离。
- 示例空间可以全部删除；没有空间时，个人档案和首页倒计时仍能独立使用。
- 删除空间会同时删除该空间中的全部记录和图表，并自动解除倒计时、进度目标与该空间的周报关联；首页目标本身不会被删除。请先确认空间数据不再需要或下载完整备份。

模板只决定字段名称和示例，不限制空间用途。例如学习模板既可以叫“考研”，也可以叫“日语”“资格证”或“每日阅读”。

## 年月与固定周条

1. 进入一个空间后点击“新建年月”。
2. 网页会自动生成该月所有以周一为开始日的周条，不需要逐周新建。
3. 每一周固定包含 Day1 到 Day7，对应周一到周日；跨月的后几天仍归入周一所在的年月。
4. 同一空间、同一年月只能建立一次。
5. “删除年月”会删除该年月的所有周计划和完成记录，但不会影响其他年月或其他空间。

每个周条使用独立的信息卡，集中显示 `WEEK 01`、日期范围和 7 天记录进度；进入年月时会优先定位到今天所在的一周，没有本周时则选择最近的一周。

旧版记录会自动迁移：原有空间会保留，旧周计划会统一对齐到周一，并自动补齐已有年月中缺少的固定周条；旧健康记录中的饮食安排与饮食记录会转成计划任务和完成记录。

## 每日计划

- 健康模板：健康重点、健康复盘和体重；饮食、运动、睡眠等都作为“计划安排”中的独立任务填写。
- 学习模板：学习重点、复盘总结和科目任务。
- 工作模板：工作重点、完成总结和事项交付。
- 空白模板：今日重点、复盘总结和通用任务。

任务的“计划”和“完成记录”分栏保存。使用 `√ / ×` 标记是否完成；当天还可以选择整体状态和嘉然、贝拉、乃琳表情。

周卡中的“已记录天数”采用明确标记：打开某一天的“设置”，在“完成得怎么样”区域点击“记录今天”并保存，这一天才会计入，周条会立即刷新；只填写计划不会自动增加天数。旧版中已经填写完成情况、复盘、小记或体重的日期会在升级时自动保留为已记录。

## 和 AI 一起规划

先建立年月、点选要安排的周条，再点击“AI 规划本周”：

1. 在一个文本框里填写与当前空间有关的真实情况、目标、时间、喜好和限制。输入提示会随健康、学习、工作或空白模板变化，这些资料只保存在当前空间。
2. 点击“生成并复制提示词”。网页会生成包含当前周固定日期和可读计划格式的专属提示词。
3. 将提示词粘贴给豆包或其他常用 AI。页面中的“打开豆包”只负责打开官方网页，不会自动发送你的资料。
4. 把 AI 返回的完整计划文本粘贴回来，点击“导入周计划”。

如果当前空间存在更早一周，提示词会自动附上上一周的完成数据，帮助 AI 调整任务量。导入只更新当前选中周的每日类型、重点和计划任务，不会生成或修改当天小记，也不会覆盖实际完成、整体状态、复盘、体重或表情。普通用户不需要接触 JSON。

## 本周便签、顺延与周报

- “本周便签”会弹出适合手机便签的普通文字。可以出门时照着便签执行，晚上回来再统一记录完成情况；不会下载 JSON 文件。
- 先点选某一天，再点击“从 DayX 起顺延一天”：所选日期之前保持不变，从所选日期到 Day6 的全部安排和记录移到下一天，所选日期清空，原 Day7 内容丢弃。执行前会再次确认。
- “显示周报”会汇总选中周的完成状态、任务、复盘、体重（仅健康模板）、表情，以及被指定显示在当前空间的倒计时和进度目标。
- “下载周报图片”会把当前周报保存为 PNG，方便发到手机或长期留存。
- “复制纯文本”可复制 Markdown 周报，适合交给 AI 做复盘或保存到其他笔记工具。

## 曲线图

每个模板会显示对应的快速示例，也可以自定义图表名称、横轴和最多三项指标。每项指标都能分别设置纵轴最小值与最大值，留空则继续自动计算。新增节点后，可以给不同曲线分别选择表情；图表支持排序、缩放和横向查看。日期节点内部建议保存为 `YYYY-MM-DD`，横轴会显示成清楚的月/日；跨年时会在第一个节点和年份切换处补充两位年份。节点只要保存了表情，就会与对应节点同步显示；密集时会自动缩小表情，而不是隐藏到点击之后。

## 数据与部署

- 点击“备份”会下载完整 JSON 备份；这里的 JSON 只用于整站数据迁移和恢复。
- 点击“恢复”可导入新版生活日记备份，也兼容旧健康日记备份。
- 想先体验有一段记录后的完整页面，可以恢复 `示例数据/考研加健身用户示例.json`。它包含考研、健身两个空间，两个倒计时，过去与当前周记录，以及学习时长、体重和训练时长曲线图；恢复前请先备份自己的真实数据。
- 需要集中检查所有功能时，可以恢复 `示例数据/全功能测试数据.json`。其中个人档案、4 个倒计时、4 个进度目标、空间关联、每日记录、表情、周报和单/多曲线节点都已填充；曲线节点故意放了较密的表情，用于检查全局视图的自适应缩放。
- 部署到不同域名或从本地文件切换到 Cloudflare 后，浏览器会把它视为不同站点，原来的本地记录不会自动跟过去；请先备份，再到新站点恢复。
- 仓库中的 `本地备份文件`、`每周截图记录` 和 `发布` 已被 `.gitignore` 排除，不应上传个人记录。

## 主要文件

- `index.html`：网站入口，Cloudflare Pages 会直接识别。
- `app.js`：空间、年月、AI 规划、周报、图表和备份功能。
- `data-model.js`：数据版本和旧数据迁移规则。
- `styles.css`、`weekly-planner.css`、`weekly-polish.css`：页面样式。
- `stickers.js`、`图片/贝拉`、`图片/嘉然`、`图片/乃琳`：轻量表情资源。
- `冷笑话.js`：默认冷笑话。
- `示例数据/考研加健身用户示例.json`：可直接通过“恢复”导入的完整体验数据。
- `示例数据/全功能测试数据.json`：覆盖首页、空间周报和密集曲线表情的全功能测试备份。

部署时需要保留上述文件及 `图片/其他图片` 的相对目录结构。
